"Bhikkhus, hay estas tres razones.
¿Cuáles tres?
Afición, odio y ofuscamiento.
Bhikkhus, pues hay estas tres razones.
Pues, bhikkhus, para abandonar estas tres razones deben suscitar estas tres razones.
¿Cuáles tres?
Para abandonar la afición deben suscitar lo asqueroso. Para abandonar el odio deben suscitar la benevolencia amistosa. Para abandonar el ofuscamiento deben suscitar el saber.
Pues, bhikkhus, para abandonar estas tres razones deben suscitar estas tres razones.
